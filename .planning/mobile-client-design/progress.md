# 移动端适配进度

## 已完成

### 上一轮：外壳与端点（3845bf5 … 141aded，6 commit）

- 底部标签栏 + 左侧抽屉，边缘手势开合
- 小说视图的移动端阅读体验（滚动/翻页两模式、沉浸工具栏、三分区手势）
- 首页 / 角色库 / 角色页 / 设置页响应式
- 加载状态：首屏骨架、刷新指示条、失败态
- 贴底浮层避开标签栏（`--mobile-tab-bar-h`）

留下的缺口：适配了**端点**（小说视图）却没适配**通道**——从首页走到小说视图这一路上，
故事工作区和编辑区在 375px 下会横向溢出。

## 未完成

- **数据通路**（最大的一块）：Capacitor 壳里跑的就是网页版，库落 IndexedDB。
  阅读包（方案乙）还没做，所以现在装出来的 APK 需要先在设备上导入才有内容。
  路线与理由见 `architecture.md` 的数据层一节。
- **分享图从阅读界面直达**：现在还埋在导出里。见 `mobile-priorities.md` 的特别一条。
- **Android 后退键**：没接 `App.addListener('backButton')`，按一下会直接退出 Activity。
- **图标与启动图**：还是 Capacitor 的默认占位。
- **「到电脑上做」提示**：后排功能的入口都还在，但没给轻提示。
- **真机实测**：本轮全部改动只在 jsdom + 推算宽度下验过，没在真手机上跑。

## 下一步建议顺序

1. 真机实测这一轮（打一个 debug APK 装上，把阅读通道走一遍）
2. 阅读包导出/导入（桌面端出包 → 手机导入），这一步做完移动端才真正可用
3. Android 后退键行为表
4. 分享图入口前移
5. 图标启动图 + 「到电脑上做」提示

顺序理由：2 是阻塞项（没有它 APK 是空的），但先做 1——本轮改的是布局，布局的问题
只有真机能暴露，而且如果布局还有硬伤，先做 2 等于在错的地基上加层。
