## 🎯 设计核心决策（不要动这几条）

### 1. 导航结构：Obsidian 式侧栏
- **主导航在左侧**（不是顶部横栏），只有 4 个顶级入口：
  - 🏠 首页
  - 📚 角色库
  - 🔧 编辑区（原"处理区"）
  - 📦 其他资产（世界书 / 预设 / 正则 / 快照的总览页）
- **两种宽度**：
  - `expanded`（180px）：图标 + 文字横排 + 可选右侧 badge
  - `collapsed`（52px）：只留图标，文字 fade-out
- **切换规则**：
  - 首页 → 默认 `expanded`
  - 角色库 / 编辑区 / 其他资产 → 默认 `collapsed`（内容优先）
  - 用户可手动切换；选择记住到 `localStorage`

### 2. 底部只有两个入口
- 🎨 主题（点开弹层选主题）
- 🔧 设置（扳手图标，不是齿轮）

**"接入 SillyTavern 目录"不放在侧栏底部**，它是一次性配置项，作为首页顶部的显眼卡片。

### 3. 二级导航因页面而异
- **角色库** → 左侧 176px 二级筛选栏（数据集分类 / 标签色点 / 系统）
- **编辑区** → 左侧 220px 二级列表（工作类型 / 处理队列 / 最近打开）
- **其他资产** → 左侧 176px 筛选栏（状态 / 类别 / 来源）+ 主区顶部分类 tabs
- **首页** → 无二级导航，直接内容布局

### 4. 主题系统 = 换 CSS 变量
- 4 套主题共享同一套变量名
- 切换机制：`document.documentElement.setAttribute('data-theme', 'cocoa')`
- **禁止在组件里硬编码颜色**，一律使用 `var(--xxx)`
- 用户偏好持久化到 `localStorage['ste-theme']`

## 🧱 变量分层（看 themes.css）

```
全局层（跨主题不变）
├── --brand           品牌橙及其变体
├── --status-*        语义色
├── --tag-*           分类色点
├── --font-*          字体栈
├── --radius-*        圆角
└── --sidenav-*       侧栏宽度

主题层（每套主题独立）
├── --bg-canvas       主区背景
├── --bg-chrome       标题栏 / 状态栏 / 侧栏
├── --bg-elevated     卡片、面板
├── --bg-elevated-strong  hover 状态或强调层
├── --border-*        边线三档
├── --text-*          文字四档：primary / body / muted / faint
├── --hover-overlay   通用悬浮反馈
└── --input-*         表单元素
```

## 🎬 关键交互

### 侧栏折叠 / 展开
```js
document.querySelector('.side-nav').classList.toggle('collapsed');
document.querySelector('.side-nav').classList.toggle('expanded');
```
- CSS `transition: width 0.2s` 已内置
- 文字随宽度 fade-out（`.side-label { transition: opacity 0.15s }`）

### 主题切换
```js
document.documentElement.setAttribute('data-theme', 'cocoa');
localStorage.setItem('ste-theme', 'cocoa');
```
- 完整实现见 `index.html` 底部 `<script>` 块

### 卡片 hover
- `transform: translateY(-2px)` · `transition: transform 0.2s`
- 底部渐变浮条不需要 hover 特殊处理

## ✅ 落地时的顺序建议

1. **先接 themes.css + layout.css**，把静态样式吃进去
2. **主题切换器接入**（可以先复用 index.html 底部的 script）
3. **主导航侧栏组件化**（React/Vue 组件都行，注意 expanded/collapsed 双态）
4. **角色库先做**（视觉最重、也是本轮设计变化最大的页面）
5. **编辑区**：外壳套上，工具栏用现有代码填回去
6. **其他资产**：卡片按 `.asset-card` 结构渲染
7. **首页**放最后，因为它需要拉真实数据（继续阅读 / 精选角色 / 统计数字）

## 📞 有疑问时

如果 agent 遇到设计上不明确的地方（例如"这个状态用什么颜色"、"这个按钮放哪"），优先原则：

1. 查 `layout.css` 有没有已定义的类
2. 查 `themes.css` 有没有对应的语义变量
3. 如果都没有 → **暂停，回来问设计**，不要凭空发挥（尤其不要发明新颜色）

用户的美学是**克制、暖、有仪式感**。宁少勿多。
