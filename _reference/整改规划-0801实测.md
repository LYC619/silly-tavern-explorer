## 1. 设计稿信息架构速记（character-detail.html 提取）

- **左信息栏（272px 固定不滚动）**：立绘 3:4（点击 lightbox 放大）→ 信息行：名称 / 类型 / 评分 / 最后游玩（绝对时间）/ 字数 / 游玩时长（tooltip 注明估算口径）→ "操作"入口 → 右侧抽屉（编辑角色卡 / 读取内置资源(?说明) / 导出角色卡 / 删除角色卡）
- **主列头部**：衬线大标题 + 铅笔（meta 编辑弹窗：展示名/作者/来源/简介，注明"只改本地展示，不写回角色卡原件"）+ "折叠简介"切换；byline（作者·来源）；简介段落；标签条（NSFW 开关+?说明 → 分组内置标签 → 虚线自定义标签 → +添加）
- **tab 导航**：故事(计数) + `›` 展开三个子 tab（总结/日记/故事树）｜备注(计数)｜关联资产(计数)｜立绘(计数)｜右侧"导入"按钮
- **故事列表**：每行 = 名称·N段聊天·相对时间 / ☆评分(未评分) + 字数 / 状态 chip（未开始/进行中/已完结/已搁置）/ 三按钮 阅读·处理·导出；当前故事左侧高亮条
- **就地阅读**：点故事在当前区域打开正文，**头部自动折叠**（返回列表自动展开）；顶部 = 返回故事列表 + 故事名 + 状态 + "在编辑器中打开"
- **总结/日记/故事树视图**：故事切换下拉 + "去处理区生成" + 过期提示（"生成于 X，之后故事又有更新，内容可能已过期"）+ 空态（未配 AI 时提示去设置）
- **备注**：按时间列出的角色级速记（玩卡心得），可新建
- **关联资产**：列表（类别 chip+名称+meta+启用态）→ 点名称开宽抽屉预览条目 → "在编辑器中打开"
- **立绘**：**分行组织**（行标题可改名，一行=一个角色或一个剧情阶段）；行内横向滚动，可展开成网格；每行可导入；每张可"设为当前"卡面（左栏立绘同步换）
- **导入弹窗**：六类型选择（故事记录/世界书/预设/正则/**引用**/立绘·卡面）+ 拖放区
- **底部状态栏**：已接入 ST 目录路径 + 版本号

## 3. 数据模型与共享层变化（10.0，先行）

- **ArchiveCharacter**：
