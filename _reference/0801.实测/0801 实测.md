## 角色库

1.简介和评分字体偏小，ST的角色图只要能看到主要部分即可，可以调大一些，或者和之前的设计一样，直接把右上角调节卡片大小的区域改成“外观”按钮，让用户自己调节卡片大小和字体大小，属于视觉体验体验的问题。。
- 标题+描述+评分+时间都压在封面图下 1/3 处，遮罩区域内信息过密；且评分显示X/10似乎没什么意义，直接显示X就行了，这样就可以把评分和更新时间都放到左上角，下方只显示角色卡名称和简介，来达到更好的效果
- 可以考虑未评分时显示"未评分"文字。
- **"x段故事"的标签位置和卡片右上角的布局。** 但白色半透明底的小标签在某些浅色卡片上对比度不够。也属于视觉体验体验的问题，可以并到前面说的”外观“按钮。
- **右上角的卡片大小滑块。** 没有任何标签或提示说明它是调整什么的，新用户需要试拖才知道。而且会随着用户滚动而滚到界面外，建议直接并入“外观”
- 截断的标题加 hover 显示全名的 tooltip 会更好。

2.**左侧筛选栏的分类逻辑混乱。** 顶部的"全部/未开始/进行中/暂停/已完成/已弃置"是按**使用状态**分类，下面的"人物/非人/其色/宝可梦/类型人物"是按**角色类型**分类，再下面"系统/批量管理"又是功能入口。三种性质不同的东西混在同一栏里，没有明确的视觉分隔，用户扫一眼不容易理解层级关系。建议给"状态"、"标签"、"操作"各加一个小标题或者分隔线。
- 这部分直接重构吧，全部统合成标签系统
- 左上角改成“标签管理”按钮，用于在弹出的弹窗内管理内置标签和自定义标签
- 然后设计一下内置标签，并在内置标签右上角附上可以悬浮显示解释说明的问号（比如人物类型的卡片就是以人物为主体构建的卡片）
	- 首先是最重要的“类型”：人物、剧情、玩法、综合、同人，这部分替代之前的游玩状态部分，在左侧边栏上方显示
	- 然后是一些简单细化，一张卡可以多选的，比如**人物/**：少女、成女、非人、群像；**剧情/**：悬疑、恋爱、冒险、历史；**玩法/**：模拟、RPG、解谜、经营、养成；**世界观**：玄幻、奇幻、科幻、现代、古风；
	- 还有就是一些联动的标签：**卡面**：SFW、NSFW，可以在设置里加个是否对NSFW的卡面进行模糊处理；“评价”标签，这个可以和用户的评分双向联动，用户输入评分后自动更新标签、选择标签后自动更新评分（取中位数整数，只在用户尚未手动评分时生效），其中低创（小于6分）、及格（6-7.5）、精品（7.5-9）、神作（9-10）
	- “类型“可以在角色卡详情界面直接下拉显示、选取
	- NSFW标签则用开关的形式，就一个开关上用来决定卡片是否为NSFW，点击打开后自动添加卡面NSFW标签，这个不知道影不影响布局，可以只在设置里启用了NSFW模糊化显示时才出现这个按钮（默认ON）
	- 左侧边栏的选择问题：类型标签只能选一个，下面的其他标签支持多选


3.顶部的评分筛选 tab（全部评分/已评分/未评分/8分以上/6分以上）直接删掉，用户通过上面设计的“评价”标签筛选。这样上方那一条区域就空出来了，可以更好的查看角色卡。

4.把批量管理挪到左上角，和搜索、排序等功能在一行

5.**卡片上的信息截断严重。** 第二行的描述文字（如 `<character_details> # YAML configuration required to sho...`）直接把原始 prompt 格式暴露给了用户。这对普通用户来说是乱码，建议做一层清洗——如果描述以代码标记开头就跳过，显示 `personality` 或 `scenario` 字段的内容作为摘要；如果都没有可读内容就显示"暂无简介"。
- 目前来看，认真写卡片简介的属于少数，做一些清洗吧，有些角色描述里的内容也不适合当简介
- 还有几种常见的"不可读"模式需要处理：以 `{{char}}` 或 `{{user}}` 占位符开头的、纯英文 prompt 指令（如 `You are a...`、`[System note:`）、以及 JSON/YAML 格式化文本。清洗优先级建议是：`creator_notes` > `scenario` > `personality` > `description` 前100字清洗后的内容 > "暂无简介"。因为 `creator_notes` 本身就是写给用户看的非 prompt 内容，最适合做摘要来源。

6.目前的时间只有导入时间和更新时间，但能大幅优化体验的还有角色卡最后一次故事的对话结束时间，这个更能帮用户回忆起是什么时候玩的这张卡。看看能否加入，并在排序里加上按游玩时间排序。而且目前排序只有A-Z，缺少Z-A，我记得应该可以通过一个按钮来实现。
- 目前全部使用相对时间（38分钟前 / 1天前 / 5天前）。相对时间超过一定跨度后信息量下降（"3个月前"不如"2025-05-01"直观）。建议：≤7 天显示相对时间，>7 天显示具体日期；所有时间 hover 显示精确到分钟的完整时间戳。

7.批量管理功能，增加批量设置标签功能柜；批量管理挪到顶部工具栏后，还需要定义进入批量模式后的交互：
- 点选 / Ctrl 点选 / Shift 范围选 / 拖拽框选（拖拽做起来比较麻烦的话可以先不做）；
- 全选当前筛选结果（而非全库）的入口；
- 已选数量的常驻提示条 + 批量操作（打标签、删除、导出）按钮位置。


8.其他补充说明（出现矛盾时以补充说明内的为准）
- 左侧标签筛选与顶部搜索栏的交互关系：确认为在搜索结果内叠加筛选（而非互斥），UI 上需要让用户感知到当前是"搜索+筛选"的叠加态，比如搜索栏旁显示当前激活的标签 chip，或者有"清除所有筛选"的快捷操作。
- 只保留 评分 → 标签 单向自动化；用户手动点"评价"标签时，弹出评分输入（预填该档区间中值）让用户确认，而不是静默写入。
- 建议：NSFW 开关始终可用（在卡片详情里），"模糊 NSFW 卡面"作为独立的全局设置项（默认关闭或按需）。两者解耦。NSFW 开关就是一个普通的布尔开关，占位很小，有几种放法都不影响布局：
	1. **放进标签编辑区**：既然 NSFW 本质是"卡面"维度的标签，可以直接作为标签选择器里的一个特殊标签（点击切换），完全不新增控件。
	2. **放在详情页的元信息行**：和评分、更新时间同一行加一个小开关或小徽标（点击切换），只占一个 icon 的宽度。
	3. **收进详情页的"更多操作"菜单**（⋯ 菜单里一项"标记为 NSFW"），对布局零影响，但可发现性略差。
- 旧状态如果不再保留就明确废弃并告知；旧自定义标签自动转为新体系的自定义标签。

