设计说明

布局改动

  • 侧栏 → 顶部横栏 tabs，把宽度让给卡片
  • 左侧改成筛选/分类栏（不是主导航）
  • 卡片 5 列，图片占满，信息浮在底部半透明层上
  • 状态栏移到窗口底部，把版本 / 挂载点 / 存储信息集中
  • 顶部搜索框全宽度，永远可用

卡片语言

  • 图片占满整张卡（模拟立绘用渐变占位）
  • 左上角编号 + 英文 code label（工业感 / 目录感）
  • 右上角"💬 X 段故事"胶囊 badge
  • 底部半透明浮条：标题 + 一句副标题 + 评分 + 时间
  • hover 时轻微上浮 2px

主题差异

  • 深咖啡 #1e1610 · 最保留品牌温度
  • 墨黑 #0e0e10 · 最贴你贴图，冷/沉
  • 深夜蓝 #0f131c · 冷底 + 暖点，数字感
  • 米色典雅 #f5f0e6 · 处理区留用
  • 四版共享同一套排版 / 组件 / 交互语言
