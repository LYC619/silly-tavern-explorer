## 核心认知（客户端项目和纯网页的区别）

1. **exe 不进 git**：`src-tauri/target/` 已在 .gitignore。客户端安装包通过 **GitHub Release 附件**分发，不是仓库文件。
2. **一次发版 = 三样东西**：git tag（代码快照）+ GitHub Release（发布说明）+ Release 附件（`STE_x.y.z_x64-setup.exe` 安装包，可再附免安装 `STE.exe`）。
3. **无签名警告**：exe 没有代码签名证书，用户下载后 Windows SmartScreen 会拦一次（更多信息→仍要运行）。README 里要写明这是预期行为；买证书或用 MS Store 是远期选项，个人项目一般不做。
4. **版本号四处同步**：package.json / `APP_VERSION`(GlobalSettings.tsx) / `public/sw.js` CACHE_VERSION / `src-tauri/tauri.conf.json`。前三处有 version-sync 测试守卫。

## 远期可选（首发不做，记录备查）

- **CI 自动出包**：tauri-action 在打 tag 时自动构建并挂 Release（省去本机打包）；需要时再搭
- **自动更新**：Tauri updater 插件（应用内检查新版本），需要签名密钥对，等用户量再说
- **代码签名**：消除 SmartScreen 警告，需购证书（年费），个人项目通常跳过
