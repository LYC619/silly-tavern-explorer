# 聊天导出精简

## 两份数据的职责

导入和归档不是破坏性压缩。STE 库内的 `故事.json` 保留聊天首行原始元数据、每条消息原始字段、swipes、隐藏楼层和插件扩展数据，是故事的唯一真源。

客户端故事目录中的 `聊天.jsonl` 与分支 JSONL 是从 `故事.json` 生成的 SillyTavern 兼容工作副本。它们不应用导出正则，也不删除 swipes。

精简只发生在用户主动导出副本时，不反向修改库内故事。

## 导出时可能发生的处理

- 未选中的 swipe 候选被清空，`swipe_id` 归零，`swipe_info` 清空。
- 用户启用插件缓存清理时，导出副本移除可识别的聊天插件缓存字段。
- 用户选择消息范围时，只输出该范围。
- 用户启用正则规则时，规则作用于导出文本。
- JSONL 继续保持可导回 SillyTavern 的形状；TXT 和 Markdown 是阅读或笔记副本。

导入提示中的“发现若干 swipes、导出时将自动清除”是体积预估，不表示导入阶段已经删除数据。原始体积与导出体积都按 UTF-8 字节估算，实际减少量取决于 swipe 数量、插件缓存和所选正则。
