# 设置导航、切页性能与迁移提示设计

## 范围

本轮只处理两组问题：

1. 设置页改为左侧分区切换，降低信息密度并避免一次挂载全部设置内容；同时改善首页与设置之间的切换卡顿。
2. 启动时先静默检查档案库 schema，仅在确实需要迁移时显示“正在升级档案库”。

两组实现分别测试、分别提交。当前累计约 5 个修复后再统一生成客户端，本轮不因单个提交重打客户端。

## 已确认原因

- `AppLayout` 使用 `AnimatePresence mode="wait"`，旧页退出 180ms 后新页才开始进入，单次切换存在约 360ms 的串行动画等待。
- 首页路由卸载后丢失组件状态，返回时重新读取角色、故事、世界书、预设、正则、总结和故事树。
- 设置页同时挂载 AI、运行设置和存储管理；存储面板进入即遍历主要档案计算容量。
- `MigrationNotice` 初始状态固定为 `running`，在确认 schema 已是最新版之前就显示升级弹窗。

## 设置页结构

桌面宽度下采用固定左侧分区导航和右侧内容区；较窄宽度下导航改为顶部横向滚动，不产生页面级横向溢出。

分区固定为：

1. 显示：NSFW 卡面默认模糊等显示偏好。
2. AI 配置：现有多提供商配置、模型列表与连通测试。
3. 目录与连接：SillyTavern 目录、STE 库目录、只读 ST 配置入口。
4. 数据与备份：容量明细、完整备份、恢复、清缓存、清空数据。
5. 关于与引导：版本、项目链接和重新体验引导。

左侧使用普通导航行，不把整页包成卡片，也不在外层卡片中继续嵌套卡片。只挂载当前分区，切换状态写入本地显示设置，离开设置页再返回时恢复上次分区。

## 切页性能

- 路由内容动画改为同步进出，时长约 120ms；侧栏、标题栏和状态栏继续常驻。
- 首页保留模块级只读快照：首次读取完成后，重新进入先显示快照，再在后台刷新文件库数据。
- 设置页只挂载当前分区，存储统计只在进入“数据与备份”时执行。
- 快照只用于首帧展示，不替代后台刷新，不改变数据写入或一致性规则。

## 迁移启动流程

启动时先读取档案库 schema 版本：

- 已是当前版本：静默放行，不显示升级弹窗。
- 版本落后：进入现有阻塞迁移流程，成功后放行。
- 检查或迁移失败：保留失败原因与重试按钮，仍不允许进入编辑页面。

一次性“整理体系升级说明”继续使用原有本地标记，仅在实际完成旧库迁移且库中存在角色时显示。

## 测试与验收

- 设置页契约测试：五个分区、单分区挂载、选项持久化、窄宽导航策略。
- 路由契约测试：同步动画且不再使用 `mode="wait"`。
- 首页缓存单测：缓存首帧可用、后台结果覆盖缓存。
- 迁移组件测试：当前 schema 静默放行、旧 schema 显示迁移、失败可重试。
- 针对性 ESLint、TypeScript 和相关 Vitest 通过后分别提交。

## 不在本轮

- 不改设置项的业务语义、AI 配置格式、目录切换规则或备份格式。
- 不引入新的全局状态框架或查询依赖。
- 不修改正式版本号、发布元数据，不 push、不打 tag。
